# Shattered Pixel Dungeon: Adventure — Legacy

The **Android 4.x edition** of an unofficial Shattered Pixel Dungeon fork with rollback saves.

This branch is based on **Shattered Pixel Dungeon 3.2.1** and is kept for old devices that cannot run modern Shattered releases. It adds one automatic floor-entry checkpoint, three manual exact-turn save slots, and recovery from checkpoints after death.

## Editions

| Branch | Based on | Android support |
| --- | --- | --- |
| [`adventure-v4`](https://github.com/thistleclaw/shattered-pixel-dungeon/tree/adventure-v4) | Shattered Pixel Dungeon 4.0.0 | Android 5.0+ |
| [`adventure-saves`](https://github.com/thistleclaw/shattered-pixel-dungeon/tree/adventure-saves) | Shattered Pixel Dungeon 3.2.1 | Android 4.0+, including Android 4.4 |

This branch is the second row: the legacy compatibility build.

See **[ADVENTURE_MODE.md](ADVENTURE_MODE.md)** for save behavior, build details and compatibility notes. Release signing is documented in **[docs/adventure-release-signing.md](docs/adventure-release-signing.md)**.

## Upstream

Adventure Mode is based on [Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon), created by Evan Debenham, which itself is based on Pixel Dungeon by Watabou.

This fork is **not an official Shattered Pixel Dungeon release**.
